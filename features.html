Features

Available now

Live endpoint

A lightweight endpoint that confirms your web server is reachable and PHP is running — without causing database load. Perfect for uptime monitors and load balancer health checks.

Admin dashboard

Find your monitoring endpoint URL and run a quick test right from the WordPress admin — no code or config files needed.

Coming soon

Readiness endpoint

An extended health check that also verifies the database connection.

System info endpoint

An extended endpoint that exposes server metrics and PHP environment details for infrastructure monitoring dashboards.

Authentication

Secure your endpoints with an API-key to prevent unauthorized access to your health check URLs.

Custom URLs

Configure your own endpoint paths via .htaccess rules instead of using the default URLs.

Access logs

Track when and how often your health check endpoints are being polled, directly from the WordPress admin.
