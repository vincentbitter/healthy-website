# Healthy Website
This repository contains the public website for WordPress plugin [Healthy](https://github.com/vincentbitter/healthy).

## Develop
### DevContainer
The easiest way to start developing is to setup a DevContainer via Codespaces or a local environment. When opening the DevContainer, just press `F5` to launch Jekyll Serve.

### Manual setup
Checkout the repository and run the follow commands to start a local preview:
```
bundle install
bundle exec jekyll serve
```
